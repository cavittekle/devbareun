# DevBareun v1.2.7 — Template System + Data Mapping Wizard

## Added
- Package-specific Excel templates for Full Project Control, Schedule Recovery, Cost & Payment Control, Material Continuity, and Risk & Decisions.
- Backend template manifest and download API.
- Preflight mapping wizard payload with required fields, detected fields, field sources, sheet confidence summary and template guidance.
- Frontend mapping preview enhancements showing required field readiness and how columns were mapped.
- Light/dark mode styling for mapping wizard components.

## Guardrail
Dashboards remain flexible: missing data is shown to the user and can be manually confirmed, but values are not invented.
