# DevBareun Icon Package

This folder contains a clean DevBareun icon/logo handoff package generated from vector symbol paths. It is intended for brand usage, previews, app icons, favicons, and lightweight design handoff.

## Included

- `svg/` - editable vector icon and logo variants.
- `png/` - transparent and dark-background PNG exports, including app icon and favicon sizes.
- `pdf/` - one-page preview sheet for sharing.
- `eps/` - vector EPS icon export.
- `preview/` - PNG brand-sheet preview.
- `manifest.json` - package inventory metadata.

## Not Included

- `.ai` is intentionally not included. Creating a real editable Adobe Illustrator file requires Illustrator or a verified export pipeline. A fake `.ai` file would be unsafe and misleading.

## Usage Guidance

Use the black logo on light backgrounds and the white logo on dark backgrounds. Use the icon-only files for favicons, app icons, loader symbols, and compact UI surfaces. Keep clear space around the icon equal to at least 25% of the icon width.
