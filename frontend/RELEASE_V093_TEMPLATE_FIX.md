This release replaces the previous empty/generic optional Excel templates with a professional multi-sheet construction upload template.

- `Download professional template` now points to `templates/devbareun-professional-upload-template-v2.xlsx`.

- The template contains: README, Full_Dashboard_Input, Cost_Estimate_Smeta, F2_Progress_Payment, Schedule_Plan_Actual, Workforce_Productivity, Equipment_Usage, Lists.
- JS-off/default link now downloads a real useful workbook instead of `#`.
