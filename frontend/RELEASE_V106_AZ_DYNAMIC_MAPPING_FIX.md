# DevBareun v1.0.6 — Azerbaijani Dynamic Mapping Panel Fix

## Fix

Dynamic upload/mapping panel text is now language-aware for EN/AZ mode.

Fixed Azerbaijani translations for:

- missing-fields panel
- optional/manual input placeholders
- planned execution, baseline finish, estimated finish labels
- mapping confidence label
- no-sheet/no-column messages
- additional actual data request card
- upload status / dashboard generation status messages

## User-visible result

When Azerbaijani mode is selected, the mapping confirmation and manual-entry section now shows Azerbaijani text instead of English/Turkish browser-translated text.
