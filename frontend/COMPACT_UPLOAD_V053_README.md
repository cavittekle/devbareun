# DevBareun v0.5.3 — Compact Upload Flow

This frontend update removes the large selected-analysis/template action block from the upload area.

Changes:
- Replaced the large selected-analysis card with a compact status strip.
- Removed the large “Use my own Excel” button.
- Kept one small “Download optional template” link.
- Upload flow is now: select analysis type → upload files → mapping preview → confirm and generate.

Backend v0.5.2 remains compatible.
