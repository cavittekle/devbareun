1. Service scope

DevBareun is designed to help customers upload construction project information and receive structured dashboard and reporting outputs for project control purposes.

2. Customer responsibility

Customers are responsible for uploading accurate project files and reviewing generated outputs before using them for management decisions.

3. Payment model

DevBareun supports both one-time and subscription access. Single Project is a one-time payment for one analysis package. Plus and Pro are monthly subscription plans with recurring analysis credits, dashboard access and report export where available.

4. Limitations

DevBareun supports project control and reporting. It does not replace official engineering judgment, contractual determinations or statutory approvals.
