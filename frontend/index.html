Security and data handling

Your project files stay private.

How DevBareun stores, checks and opens the files you upload.

Private storage

Uploaded files are kept in a private storage bucket, never behind a public link. Access rules tie each file to the account and project it belongs to.

Short-lived signed links

Files are uploaded and read through signed links that expire after a short time, so a copied link soon stops working.

File checks before analysis

Only project file types are accepted and executable files are rejected. Each file's content is checked against its type before it is read.

Payments through Lemon Squeezy

Checkout runs on Lemon Squeezy. Your card details go to the payment provider and are never stored by DevBareun.
