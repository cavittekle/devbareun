# DevBareun v0.8.2 — Dashboard Light Mode Readability Fix

This frontend patch improves dashboard readability in light mode.

## Fixed
- Result dashboard KPI titles and values are now dark and readable in light mode.
- Analysis-specific dashboard cards use white surfaces and darker text in light mode.
- Muted labels, notes, panel rows, table headers and export language controls have stronger contrast.
- Landing-page mock dashboard cards also receive stronger light-mode contrast.

## Backend
No backend changes in this patch. Use the latest deployed backend version with this frontend.
