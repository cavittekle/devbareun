DevBareun may collect project files, contact details and usage information required to prepare construction analytics, dashboards and reporting outputs.

Uploaded files may include schedules, reports, cost tables, BOQ summaries, workforce data and site documentation. These files should be handled only for the requested project analysis and reporting workflow.

3. Data security

Project data should be protected with access control, secure authentication and controlled storage rules. Commercial deployment should use encrypted connections and restricted user access.
