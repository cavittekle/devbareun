Frequently asked questions

Key answers about project upload, dashboard creation, reports and data security.

You upload the baseline schedule, actual progress at the data date and, if you keep them, delay events. DevBareun runs the construction execution and delay analysis and returns a delay dashboard plus the execution report: progress, SPI, schedule delay in days, forecast completion, critical path and delay responsibility.

Three kinds of documents: the contract (PDF, Word or photo), the planning (DevBareun Excel template, other Excel/CSV plan-actual tables, Primavera P6 XER, MS Project XML or .mpp, PDF) and F2 certificates (Excel or Word). Delay is calculated from the Excel, CSV, XER or MS Project XML schedule; F2 amounts are compared with physical progress; the contract, PDF schedules and .mpp files are kept with the report as references. Column headers in English, Azerbaijani, Turkish and Russian are recognised.

Planned progress at the data date comes from the baseline. SPI is actual % divided by planned %. Schedule delay is the number of days between the data date and the date on which the baseline reached today's actual progress (earned schedule). Forecast completion uses actual finishes, reported forecasts, production rates and predecessor logic, and the critical path comes from total float.

DevBareun offers both a one-time and a subscription model. Single Project ($29) is a one-time payment for one analysis. Plus ($49/month) and Pro ($89/month) plans provide monthly analysis credits for teams with recurring project needs. In all cases, you upload files, review the preview, and unlock the dashboard once payment is confirmed.

A delay dashboard in the workspace, and the execution and delay analysis report as PDF and Excel, in Azerbaijani or English.

Project data security is a core requirement for the platform. Uploaded files are protected with access control, secure authentication and controlled retention rules.

Single Project is a one-time $29 checkout. Plus is $49/month for 5 analysis credits, and Pro is $89/month for 20 analysis credits.

Each delay event carries a responsible party. Days are classified per calendar day: employer delay is excusable and compensable, neutral delay (for example weather) is excusable but not compensable, contractor delay is non-excusable, and days where employer and contractor delay overlap are counted as concurrent.

Uploaded files are transferred through secure connections and kept behind account-level access controls. Access is limited to your workspace, and files can be deleted on request or when the related account is closed.

Yes. The example report is open to everyone, and the upload check shows which files were recognised before payment. Payment is required only to unlock the full report for your own project.
