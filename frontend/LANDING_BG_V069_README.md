# DevBareun v0.6.9 — 3D Abstract Building Outline Background

This frontend release applies the approved construction-themed background:

- Uses an abstract 3D neon building-outline image as the hero background.
- Keeps the buildings as contour/edge lines rather than realistic imagery.
- Preserves animated light dots along the grid lines.
- Keeps mobile performance lightweight and hides the heavy background on small screens.
- Keeps `prefers-reduced-motion` behavior from the previous release.
