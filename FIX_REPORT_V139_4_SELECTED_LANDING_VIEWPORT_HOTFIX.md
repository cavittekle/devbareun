# DevBareun v1.3.9.4 — Selected Landing Viewport Hotfix

This hotfix corrects the selected landing header/hero implementation after visual review.

## Fixes
- Reduced excessive desktop hero vertical spacing.
- Hero content now starts near the header instead of appearing far below the fold.
- Header controls are balanced across 1366–1500px desktop widths.
- Added responsive breakpoints that hide low-priority nav items before the header becomes cramped.
- Dashboard preview height reduced for first-screen visibility.
- Landing page now initializes Azerbaijani copy on first load of this release.
